# Darwin_EckerdCollege
As I was completing my first degree in Marine Science with a minor in Computer Science I was exposed to Project Darwin that started in 1993. It was a pioneering Machine Learning program that used the dorsal fins of dolphins for identification. https://sourceforge.net/projects/darwin-ec/

This experience led me to study birds of prey in the Galapagos off a sailing vessel and work on Sun SPARCstations.
