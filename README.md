# Darwin_EckerdCollege
As I was completing my first degree in Marine Science with a minor in Computer Science, I was exposed to Project Darwin which began in  1993. It was a pioneering Machine Learning based scientific research system that used the dorsal fins of dolphins for identification. http://darwin.eckerd.edu/?page=project_info.html  

With a minor in Computer Science, I also worked on Sun Spark Stations to develop web pages with Netscape beta and on ray tracing and vector graphics using POV-Ray and coding in C++ . In those days working on code for 2h and processing overnight to get a single frame was consider 'fast' and not possible at home!

These would become the backbone of CGI and ML (AI) systems of today.
